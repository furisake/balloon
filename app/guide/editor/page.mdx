# Editor / Preview の使い方

Editor は入力停止から 500ms 後に、原稿名、本文、選択位置、表示位置を自動保存します。次回起動時に保存した原稿を復元します。

上部ツールバーからルビ、傍点、見出しの記法を入力できます。Undo、Redo、CodeMirror 標準の検索・置換も利用できます。下部には保存状態、原稿文字数、表示本文文字数、行数を表示します。

## Import / Export

メニューから UTF-8 または Shift_JIS の `.txt` を読み込めます。Export は Shift_JIS、改行 CRLF です。変換できない文字がある場合は書き出さず、Editor 内に理由を表示します。

Preview は原稿を青空文庫記法として解析して表示します。Reader とは別の表示設定が保存されます。
